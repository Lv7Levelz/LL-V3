## GitHub Pages upload
1. Extract the ZIP.
2. In the GitHub repo choose **Add file → Upload files**.
3. Drag **all extracted files** into the repository root (not the ZIP itself).
4. Commit.
5. Under **Settings → Pages**, deploy from `main` / `(root)`.

All HTML, CSS, JS and image assets intentionally live at repository root to prevent the previous `assets/` path issue.
