# Levels Local Version 3

GitHub-ready single-page landing site based on the approved dark futuristic Levels Local V3 concept.

## Files
- index.html
- styles.css
- script.js
- 404.html
- robots.txt
- assets/

## Upload to GitHub Pages
Extract the ZIP and upload everything inside this folder to the root of the repository.
Then enable GitHub Pages from `main` / `(root)`.

## Note
The concept artwork is used as the visual reference and cropped into web assets.
The live site uses Oxanium + Inter from Google Fonts as practical web equivalents to the concept typography.
Unsupported performance claims and fake partner/customer counts from the mockup have deliberately not been carried into the live copy.
